# 2747. Count Zero Request Servers

You are given an integer n denoting the total number of servers and a 2D 0-indexed integer array logs, where logs[i] = [server_id, time] denotes that the server with id server_id received a request at time time.

You are also given an integer x and a 0-indexed integer array queries.

Return a 0-indexed integer array arr of length queries.length where arr[i] represents the number of servers that did not receive any requests during the time interval [queries[i] - x, queries[i]].

Note that the time intervals are inclusive.

```ts
function countServers(n: number, logs: number[][], x: number, queries: number[]): number[] {
    const res = [];
    let left = 0, right = 0;
    const window = new Map<number, number>();

    const sortedLogs = logs.toSorted((a, b) => a[1] - b[1]);

    const sortedQueries = queries
        .map((time, index) => [time, index])
        .toSorted((a, b) => a[0] - b[0]);

    const add = (id: number) => window.set(id, (window.get(id) ?? 0) + 1);

    const remove = (id: number) => {
        const prev = window.get(id)!;
        if (prev === 1) {
            window.delete(id);
        } else {
            window.set(id, prev - 1);
        }
    };

    for (const [query, index] of sortedQueries) {
        while (right < sortedLogs.length && sortedLogs[right][1] <= query) {
            add(sortedLogs[right][0]);
            right++;
        }

        while (left < right && sortedLogs[left][1] < query - x) {
            remove(sortedLogs[left][0]);
            left++;
        }

        res[index] = n - window.size;
    }

    return res;
};
```
